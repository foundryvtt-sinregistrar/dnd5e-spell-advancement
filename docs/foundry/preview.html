English

Native D&D5e spell-choice advancements for PHB 2024 classes and selected subclasses in Foundry VTT.

Features

  • Native advancements: Uses D&D5e ItemChoice advancements and the system’s own Compendium Browser.
  • Supported classes: Cleric, Bard, Druid, Sorcerer, Warlock, Ranger, Paladin and Wizard (PHB 2024).
  • Supported subclasses: Eldritch Knight and Arcane Trickster when the corresponding PHB content is installed.
  • Level-aware filtering: Limits spell choices to levels available to the actor; the visible range can be narrowed.
  • Special class rules: Bard Magical Secrets from level 10; Wizard spells enter the spellbook unprepared.
  • Official content remains intact: Adds advancements to embedded actor class/subclass items without editing official compendiums.

Requirements

Foundry VTT 14.367+ (verified on 14.368) and D&D5e 6.0.5+ (verified on 6.0.5). Relevant official PHB 2024 content must be installed separately.

Installation

  1. Install the compatible D&D5e system and any official content you need.
  2. Install the module using its Manifest URL or from Foundry’s package browser when available.
  3. Enable it in your D&D5e world, then create a supported class character or level up.

Manifest URL: https://raw.githubusercontent.com/foundryvtt-sinregistrar/dnd5e-spell-advancement/main/module.json

Existing characters

Existing actors are not updated automatically. A GM can analyze and process compatible existing actors through the module settings; owners can also use the API. Imported spells can be reconciled as historical choices. See the README (Spanish) for the supported API calls and class identifiers.

Notes

No new spell compendium content is bundled. Replacing prepared spells after a long rest or level-up is not automated. Some subclass behavior, including Arcane Trickster identification, requires in-world verification.

Español

Avances nativos para elegir conjuros en clases y subclases del PHB 2024 de D&D5e para Foundry VTT.

Características

  • Avances nativos: Utiliza avances ItemChoice y el navegador de compendios del propio sistema D&D5e.
  • Clases compatibles: Clérigo, Bardo, Druida, Hechicero, Brujo, Explorador, Paladín y Mago (PHB 2024).
  • Subclases compatibles: Caballero arcano y Tramposo arcano cuando está instalado el contenido correspondiente del PHB.
  • Filtrado por nivel: Limita los conjuros a los niveles disponibles para el actor y permite acotar el intervalo visible.
  • Reglas especiales: Secretos mágicos del Bardo desde nivel 10; el Mago incorpora conjuros al libro sin prepararlos.
  • Contenido oficial intacto: Añade avances a los ítems embebidos de clases y subclases sin modificar compendios oficiales.

Requisitos

Foundry VTT 14.367+ (verificado en 14.368) y D&D5e 6.0.5+ (verificado en 6.0.5). El contenido oficial del PHB 2024 correspondiente debe estar instalado por separado.

Instalación

  1. Instala el sistema D&D5e compatible y el contenido oficial que necesites.
  2. Instala el módulo mediante su URL de manifiesto o desde el catálogo de Foundry cuando esté disponible.
  3. Actívalo en tu mundo D&D5e; crea un personaje de una clase compatible o sube de nivel.

URL del manifiesto: https://raw.githubusercontent.com/foundryvtt-sinregistrar/dnd5e-spell-advancement/main/module.json

Personajes existentes

Los actores existentes no se modifican automáticamente. Un GM puede analizar y procesar los actores compatibles desde los ajustes del módulo; los propietarios también pueden usar la API. Los conjuros importados pueden reconocerse como elecciones históricas. Consulta el README para las macros e identificadores disponibles.

Notas

No incluye nuevos compendios de conjuros. No automatiza el reemplazo de conjuros preparados tras un descanso largo o una subida de nivel. Algunas funciones de subclases, como la identificación del Tramposo arcano, requieren comprobación en una partida.
